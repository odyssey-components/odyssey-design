# Component Quality Audit

本审计以 Ant Design 6.6.1 与仓库内 shadcn 实现的成熟状态覆盖为参照，以 Odyssey 的 Base UI adapter、组合式 API、Token、稳定 anatomy 和跨端无障碍约束为准。P0 表示语义、表单、焦点或键盘错误；P1 表示公共契约或常用状态缺口；P2 表示便利性、视觉变体或文档增强。本轮未发现需要阻断发布的 P0，Radio、选择与输入控件 P1 已完成。

## 后续批次

全部 P1 已完成。后续 P2 按实际产品需求选择视觉变体和文档增强；每批仍须同步 Catalog、生成 API、迁移说明和实际消费方测试。
