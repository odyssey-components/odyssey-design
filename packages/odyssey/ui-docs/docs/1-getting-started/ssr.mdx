# SSR

Odyssey 模块初始化和首次渲染不访问浏览器 API。`colorScheme="system"` 在服务端使用 light 快照，hydration 后再同步系统模式。

服务端使用 styled-components 的 `ServerStyleSheet` 收集样式。正式应用应让 `App` 包含 `OdysseyProvider`；Provider 会收集一套 Base 与 Core 组件规则，规则大小不会随组件实例数增长：

```tsx
const sheet = new ServerStyleSheet();
const html = renderToString(sheet.collectStyles(<App />));
const styles = sheet.getStyleElement();
sheet.seal();
```

组件级 SSR 测试或小型独立片段可以不挂 Provider。此时组件通过内部 fallback 收集自己的 Runtime Styles，公开组件调用方式不变。嵌套 Provider 各自拥有一套运行时规则和主题上下文；Portal 继续使用最近 Provider 的 portal host。

Starter 也会先使用配置默认值渲染，挂载后再读取 localStorage，避免 hydration 不一致。
