# ProRadioGroup

## 何时使用

当选项来自数组并且不需要自定义 Core anatomy 时使用。普通选项和按钮式选项共享 Core RadioGroup 的表单、键盘和无障碍行为。

<ComponentDemo id="proRadioGroup" />

`renderOption` 只定制标签内容；选择状态、隐藏 input 与交互仍由 Core 管理。需要完全自定义结构时直接使用 `@odyssey/ui/radio-group`。

## 无障碍

必须通过 `aria-label`、`aria-labelledby` 或外部 Field 为组提供可访问名称。方向键在选项间移动，Space 选择当前项；自定义 `renderOption` 应保留可理解的文本标签。
