# Field

## 何时使用

Field 负责标签、说明、错误信息和控件的布局，不接管表单状态。

~~~tsx
<Field invalid>
  <FieldLabel>邮箱</FieldLabel>
  <FieldContent>
    <Input />
    <FieldDescription>用于接收通知。</FieldDescription>
    <FieldError>请输入有效邮箱。</FieldError>
  </FieldContent>
</Field>
~~~

Field 支持 vertical、horizontal 和 responsive；responsive 会按 FieldGroup 的 32rem 可用宽度切换布局。Odyssey 控件会自动关联标签、说明、错误与状态，显式 ID 仍然有效。

## 无障碍

FieldError 使用实时警告语义，并由 Field 自动加入控件的可访问描述。
