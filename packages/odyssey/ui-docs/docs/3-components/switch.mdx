# Switch

## 何时使用

用于立即生效的开关。需要提交确认的设置应改用 Checkbox。

`size="sm | md | lg"` 同时调整轨道、Thumb 和粗指针点击目标。异步提交反馈由调用方组合，Core 不提供 loading 或 checkedChildren。

<ComponentDemo id="switch" />

## 无障碍

Switch 必须有描述其设置项的可访问名称，聚焦后使用 Space 切换状态。
