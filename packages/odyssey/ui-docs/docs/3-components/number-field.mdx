# Number Field

## 何时使用

Number Field 基于 Base UI，使用 `number | null` 表达值。它保留组合式 anatomy，业务表单可在输入框两侧自由安排步进按钮，或单独加入 scrub area。

<ComponentDemo id="numberField" />

## 键盘与无障碍

方向键、Home 和 End 调整数值；FieldLabel 或 `aria-label` 为输入框提供名称。粗指针环境保留足够大的步进按钮点击区域。
