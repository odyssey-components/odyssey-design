# Skeleton

## 何时使用

用于内容结构已知、仍在等待数据时的装饰性占位。支持 text、rectangular、circular 形状，以及 wave、pulse、none 动画；复杂页面骨架由多个 Skeleton 组合。

<ComponentDemo id="skeleton" />

## 无障碍

Skeleton 始终对辅助技术隐藏，加载状态和可理解文案应由外层区域或 Spinner 提供。系统开启 reduced-motion 时，wave 与 pulse 都停止动画。
