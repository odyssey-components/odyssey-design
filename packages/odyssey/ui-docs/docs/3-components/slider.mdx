# Slider

## 何时使用

Slider 用于在连续或分段范围中选择数值。使用 Root、Control、Track、Indicator 和 Thumb 组合；每个 Thumb 必须提供可辨识的无障碍名称。

## 键盘与无障碍

方向键按 step 调整，Home/End 跳至边界。多 Thumb Slider 应分别设置 `aria-label`。
